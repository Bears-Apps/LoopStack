# LoopStack Meal Trace Handoff

This bundle contains:

- `CLAUDE_SETUP_PROMPT.md` — paste this into Claude Code first.
- `starter-code/` — suggested TypeScript/React starter files for the meal trace, activity, and learning architecture pass.

Recommended use:

1. Add this folder to your project context or upload it to Claude Code.
2. Paste `CLAUDE_SETUP_PROMPT.md`.
3. Ask Claude to review first, then proceed step by step.
4. Do not let Claude blindly copy the starter files without reading your actual codebase first.

The starter code is intentionally modular and conservative. It is meant to be adapted to the current LoopStack file names, HealthKit API shape, and UI component structure.
